How to Set Up Free Firebase Cloud Sync

100% Free • Takes 3 minutes • Syncs phone, laptop & tablet

1 Create a Free Project

Go to console.firebase.google.com, log in with Google, and click "Add project". Name it Vtrades and hit Continue (Google Analytics is optional).

2 Enable Email/Password Authentication

In your Firebase dashboard sidebar, click Build $\rightarrow$ Authentication. Click "Get Started", select Email/Password, switch it to Enabled, and click Save.

3 Create Cloud Firestore Database

In the sidebar, click Build $\rightarrow$ Firestore Database, then click "Create database". Choose your nearest server location and choose "Start in test mode" (so you can immediately read and write data). Click Enable.

4 Copy Web Configuration into Vtrades

Click the Gear icon ⚙️ (Project settings) at top left. Scroll down to "Your apps" and click the Web icon </>. Register app name Vtrades Web, copy the firebaseConfig object, and paste it into our "Firebase Cloud Settings" modal!
